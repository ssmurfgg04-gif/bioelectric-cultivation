# Stage-5 External Storage Protocol — Pattern Persistence Beyond Every Carrier

**Status:** machine-verified at the model level (exp80, 6/6; ledger L61).
**Predecessors:** exp63 (digital round-trip), exp79 (the star architecture), L60.

## The Claim

A morphogenetic pattern can be persistently stored in an external medium,
survive the total destruction of the substrate that produced it, and be
re-instantiated on a fresh substrate — provided the re-instantiation uses
the identity architecture (L60: identity strength + non-diffusing anchor +
non-junctional read). The medium carries the SPEC; the architecture makes
the FORM. Neither alone is the pattern (ES-G6).

## The Four Steps (each machine-checked in exp80)

### 1. CAPTURE — the identity-at-coordinate map

Serialize the pattern as a positional identity map: `coordinate -> target
membrane voltage`, plus capture metadata (contrast, head fraction, source
substrate). Model semantics: the M28 dual field — `phi_spec` is the
positional spec captured at pattern set (exp28's D3: the pattern is a
distributed collective property, not a cell property). Wet-lab readout:
whole-tissue voltage mapping; the 4D atlas record (MED42172041) supplies
the lineage-resolved reference for what the map must contain (ARZ
dynamics, Mediator8, underdamped recovery — the capture must be
multi-field, not single-snapshot).

### 2. STORE — the medium is ageless

Bytes do not drift (ES-G5: 1,000 storage generations, zero drift). The
biological analogs, in increasing fidelity: (a) digital storage (the map
itself); (b) the cryptic-tissue state (M31: the re-cut interval stores the
pattern invisibly in living tissue — validated as a hidden-state readout);
(c) the graft bank (Saito 2003, DOI 10.1002/dvdy.10246 — transplanted
tissue carries stored fields). The protocol accepts any medium that
preserves the map's bit-exactness or its tissue-equivalent.

### 3. DESTROY — nothing carries over but the file

The source substrate is discarded entirely. exp80's destruction arm
re-instantiates on a different-size (n=150 vs n=100), different-topology
(random-regular vs chain), different-seed destination. The pattern is not
a property of any cell, any tissue, or any substrate (D3 taken to the
medium level).

### 4. RE-INSTANTIATE — under the protocol's operating point

Write the loaded map onto the destination at the L60 star point: identity
strength `gamma = 64x` baseline (channel-expression lock), non-diffusing
anchor `mu = 0` (the epigenetic-spec semantics: identity does not ride the
junctions), and the non-junctional anterior read for form regeneration.
Verification: (a) the write holds (ES-G2: grid 0.10 mV, scale-free
0.57 mV); (b) the form regenerates after amputation (ES-G4: V 0.62 /
theta 0.62 through the reader).

**ES-G6 (the load-bearing gate):** the same file at the baseline
operating point (gamma=0.25, mu=0.015) FAILS on scale-free (11.92 mV).
The re-instantiation architecture is a REQUIRED PART OF THE PROTOCOL —
this is the exp79 theorem in protocol form: the pattern in storage + the
identity architecture = the form; either alone is not the pattern.

## What This Closes

- Stage-5 90% item "external storage": CLOSED at the model level (6/6).
- The storage is substrate-independent, destruction-proof, ageless in the
  medium, and honest about its one requirement: the architecture.
- Open residuals: the wet-lab operating point is a research program
  (channel-expression lock at 64x is not a validated protocol); the
  capture map's multi-field content (the atlas's lineage layers) is
